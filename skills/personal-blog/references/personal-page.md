# personal-page 集成与展示参考

这是本次工作验证过的站点入口索引。先确认当前仓库和相应文件仍然一致；无需为了写草稿读取整仓。项目现有约定继续以仓库文档和 AGENTS.md 为准。

## 内容落点

- 从当前工作区定位包含 `content.js` 和 `scripts/build-articles.mjs` 的 personal-page 仓库，不假定本机盘符；远端为 `drunk-cat423/personal-page`，正式站 `https://linyouwei.top/`。
- `content.js`：文章、作品等数据；文章按 `dateISO` 倒序。文章正文和已确认版本是唯一内容来源，不直接只改生成 HTML。
- `scripts/build-articles.mjs`：生成 `posts/<id>.html`，包括静态正文、目录、阅读时间、前后篇与阅读辅助组件。
- `article.css`：阅读页样式。`site.js`：导航、目录高亮、文章阅读进度。`context-animation.js`：当前 PA 文章的矢量动画。
- `assets/waymarks/`：木牌、叠石、路旗、足迹、山顶等彩铅风格 SVG；正文小标题生成时自动使用。

最小数据形态（实际字段以当前生成器为准）：

```js
{
  id: 'stable-article-id',
  category: 'tech', categoryName: '技术',
  dateISO: 'YYYY-MM-DD', date: 'YYYY.MM.DD',
  title: '文章标题', excerpt: '一两句摘要',
  intro: ['可选引言段落'],
  sections: [
    { id: 'stable-section-id', title: '小标题', paragraphs: ['正文段落'] }
  ]
}
```

类别有 `tech/技术`、`life/生活`、`ramble/碎碎念`。日期使用用户所在时区和客户端日期；不要从构建服务器日期推断。

当前段落支持转义后的行内反引号、粗体及完整 text 围栏代码块。不要把 Markdown 解析能力想象成完整通用解析器，也不要插入任意未转义 HTML。

用户已授权删除占位文章时，同时移除文章数据与对应 `posts/` 文件，再生成所有文章以更新前后篇。生成器不会自动清除已移除 ID 的旧 HTML。只删除指定或明确属于占位的那篇，检查是否还被其他位置引用。

## 图示与动效

当前 `section.animation` 的形态：

```js
animation: {
  afterParagraph: 19, // 从 0 开始的段落索引，插入在该段之后
  src: '../assets/animations/pa-context.svg',
  caption: '图示说明；数值仅示意时注明'
}
```

生成器在构建时将仓库内可信 SVG 内联，按需挂载动画模块。正文初始 SVG 应有可读状态，禁用 JS 时仍能理解。新主题先检查现有动画是否适用；不要拿 PA 专用的节点 ID 和驱动逻辑去播放任意 SVG。

- 讲解上下文等机制，使用可缩放的矢量文字、卡片、线条与进度条。小尺寸手绘标记可用不规则轮廓、低饱和色块和细线排线表达彩铅质感，沿用现有资产，不必引入绘图框架。
- 自播放动画正常情况下在进入可视区后播放；离屏、页面隐藏时停帧，回到可见区继续。减少动态效果默认静态，并允许明确的手动播放。当前用户偏好循环、暂停与重播。
- 连续帧必须保留时间基准；只在暂停或恢复时重置，避免每帧清零使动画永远不前进。不要在视口外持续更新 DOM。
- 预览可以有解释栏和步骤导航，嵌文时按用户选择裁减。当前 PA 图仅保留聊天资料窗口和上下文占用条。

## 阅读辅助的现状

小标题已有装饰性 `img.post-section-mark` 与标题文字 `span`，图标 alt 为空、对辅助技术隐藏。新增文章会继承，不要重复手工装饰目录标题。

`.post-reading-tools` 将阅读进度与“回到顶部”垂直居中排列，间隔 12px。当前进度圆直径 46px；桌面等于原胶囊按钮 23px 圆角半径所对应的圆，手机与 46px 回顶圆钮同大。将来尺寸改动需量取当前按钮，不能永远假定 46px。

进度以正文末尾进入视口为终点，页脚不计入：`end = content.bottom + scrollY - innerHeight + 32`，滚动位置除以 end 并截在 0–100%。一屏内已容纳全部正文时可为 100%。仅整数变化时更新百分比、CSS 环和 aria 值；无 JS 时隐藏不会更新的进度，保留回顶原生锚点。

## 最窄验证路径

```powershell
node scripts/build-articles.mjs
git diff --check
node server.mjs 4173
```

端口占用时先确认是不是本仓库的已有预览进程；可复用或换空闲端口，不盲目终止其他服务。该预览只监听本机，无 npm 运行依赖。

按改动选用已有浏览器工具或临时 Playwright：

- 内容：新文出现在首页/分类中；引言、章节、段落完整；正文可与确认稿重建对比；所有目录和前后篇目标存在。
- 视觉：桌面和手机实际截图，确认图标层次、长标题换行、无横向溢出。高 DPI 截图可辨认 SVG 是否清晰，但仍要检查实际 CSS 尺寸。
- 交互：目录锚点、回顶、进度 0/中间/100 及反向滚动；视口、字体、折叠目录变化后进度重算。动画验证真实经过关键阶段和循环。
- 无 JS：正文、目录、手绘标记、回顶与静态示意保持可读。

`outputs/` 属于忽略目录，适合一次性截图和验证脚本，不进入发布包。现有 `outputs/check-*.cjs` 只是本次机器上的可选历史工具，不当作技能必需文件。无必要不新增测试框架或项目依赖。

补充排障：本地 `server.mjs` 目前不支持视频 Range，曾出现 `seeked` 触发但 currentTime 回到 0。若交付确需视频，需在支持 Range 的预览/线上验证实际时间；不能只等事件。原生 SVG 路径没有该问题。
