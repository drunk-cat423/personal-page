# 设计约定

## 方向与结构

页面采用白纸底色、蓝色钢笔线条和淡水彩插画，保留轻盈的日记感。首页从开场向下依次呈现文章、作品、留言和关于；子页面沿用共享页眉、内容宽度和页脚。避免用大面积网格、假产品截图或无内容的占位卡片填充页面。

文章、作品、留言和关于各有独立 HTML 页面。文章筛选使用 `?category=tech` 或 `?category=life`，文章与作品详情通过 `?id=` 读取 `content.js` 中的稳定 ID。新内容先补进共享数据，再由首页和目录页按需呈现。

## 字体和阅读层级

- 模块标题使用本地霞鹜文楷子集；只有说明中列出的码位由它绘制，其他字符应自然回退。
- 文章和作品标题使用宋体，无衬线体承担日期、类别和表单等辅助信息。
- 正文保持清楚的字号、行距和段落宽度。避免把核心文字烘焙进插画或缩成难读的装饰。
- 常规正文链接应明确表达目的；详情页保留可见的列表返回入口。

## 窄屏与交互

640px 以下使用窄屏导航和单列内容。作品行可以在宽屏中图文并列，窄屏按阅读顺序堆叠。不要让文本或长昵称撑出视口。

所有控件都应可键盘操作并保留清楚的焦点状态。导航菜单同步 `aria-expanded`，Escape 和窗口跨越 640px 断点时关闭。插画自动播放，尊重系统减少动态偏好，离屏或页面隐藏时显示静态图。

## 内容与示例边界

`content.js` 是文章、作品和公开示例留言的单一内容源。保留“初版预览·内容为示例”的说明，不编造真实联系资料。留言演示只保存在当前浏览器，不把本地条目混入公开示例列表。
